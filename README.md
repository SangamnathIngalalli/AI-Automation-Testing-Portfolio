## 🧪 Project 01 — LLM Testing Fundamentals

A foundational automated testing project for an LLM-powered application.

**Focus:** Functional testing, negative testing, edge cases, out-of-domain scenarios, prompt variations, error handling, Pytest, API testing, and mocking.

🔗 [**View Project 01 Repository →**](https://github.com/SangamnathIngalalli/llm-testing-fundamentals)

## 📊 Project 02 — DeepEval LLM Evaluation

Extends functional testing into **semantic evaluation**, focusing on the quality of AI-generated responses rather than only application execution.

**Focus:** DeepEval, answer relevancy, correctness, safety, out-of-domain evaluation, LLM-as-a-Judge, and automated evaluation.

🔗 [**View Project 02 Repository →**](https://github.com/SangamnathIngalalli/deepeval-llm-evaluation)

---

## 🏆 Project 03 — Golden Dataset for AI Testing

Builds a reusable **Golden Dataset** for structured AI testing and regression evaluation.

**Focus:** Human and synthetic test cases, dataset versioning, JSON Schema, Pydantic validation, DeepEval, LLM-as-a-Judge, and AI test data engineering.

🔗 [**View Project 03 Repository →**](https://github.com/SangamnathIngalalli/golden-dataset-ai-testing)

---

## 🧪 Project 04 — AI Chatbot Testing & Regression Framework

A multi-turn conversational AI testing framework that evaluates chatbot behavior across realistic conversation scenarios.

**Focus:** Context retention, knowledge retention, role adherence, completeness, hallucination, safety, bias, regression testing, failure analysis, DeepEval, and HTML reporting.

🔗 [**View Project 04 Repository →**](https://github.com/SangamnathIngalalli/ai-chatbot-testing-framework)

---

## 📚 Project 05 — RAG Document Question Answering

A Retrieval-Augmented Generation (RAG) project that tests document retrieval and grounded question answering over a controlled knowledge base.

**Focus:** Document ingestion, chunking, SentenceTransformers embeddings, ChromaDB retrieval, Claude-based generation, out-of-domain refusal testing, DeepEval, answer relevancy, faithfulness, contextual relevancy, and LLM-as-a-Judge.

🔗 [**View Project 05 Repository →**](https://github.com/SangamnathIngalalli/rag-document-qa)

## 🔗 Testing Progression

The projects build progressively from traditional test automation toward AI-specific quality engineering:

**Functional Testing → Semantic Evaluation → Golden Dataset Engineering → Multi-Turn AI Testing & Regression → RAG Evaluation**

| Stage | Question |
|---|---|
| **Project 01** | Does the AI application behave correctly? |
| **Project 02** | How good is the generated AI response? |
| **Project 03** | How can reusable evaluation data support AI quality and regression? |
| **Project 04** | How does the AI behave across realistic multi-turn conversations? |
| **Project 05** | Can the AI retrieve relevant documents and generate grounded answers from them? |
