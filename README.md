## 🧪 Project details

### Project 01 — LLM Testing Fundamentals

A foundational automated testing project for an LLM-powered application.

**Focus:** Functional and negative testing, edge cases, out-of-domain scenarios, prompt variations, error handling, Pytest, API testing, and mocking.

🔗 [View Project 01 repository →](https://github.com/SangamnathIngalalli/llm-testing-fundamentals)

### Project 02 — DeepEval LLM Evaluation

Extends functional testing into **semantic evaluation**, assessing generated responses beyond simple execution success.

**Focus:** DeepEval, answer relevancy, correctness, safety, out-of-domain evaluation, LLM-as-a-Judge, and automated evaluation.

🔗 [View Project 02 repository →](https://github.com/SangamnathIngalalli/deepeval-llm-evaluation)

### Project 03 — Golden Dataset for AI Testing

Builds reusable evaluation data for structured AI testing and regression.

**Focus:** Human-authored and synthetic cases, dataset versioning, JSON Schema, Pydantic validation, DeepEval, and LLM-as-a-Judge.

🔗 [View Project 03 repository →](https://github.com/SangamnathIngalalli/golden-dataset-ai-testing)

### Project 04 — AI Chatbot Testing & Regression Framework

A multi-turn conversational AI testing framework that evaluates chatbot behavior across realistic conversation scenarios.

**Focus:** Context and knowledge retention, role adherence, completeness, hallucination, safety, bias, regression testing, failure analysis, DeepEval, and HTML reporting.

🔗 [View Project 04 repository →](https://github.com/SangamnathIngalalli/ai-chatbot-testing-framework)

### Project 05 — RAG Document Question Answering

A Retrieval-Augmented Generation (RAG) project that tests document retrieval and grounded question answering over a controlled knowledge base.

**Focus:** Document ingestion, chunking, SentenceTransformers embeddings, ChromaDB retrieval, Claude-based generation, out-of-domain refusal testing, DeepEval, answer relevancy, faithfulness, and contextual relevancy.

🔗 [View Project 05 repository →](https://github.com/SangamnathIngalalli/rag-document-qa)

### Project 06 — RAG Testing with DeepEval

An evaluation framework that examines retrieval quality and answer generation separately, then checks the complete RAG flow. It also includes judge validation against human-labeled examples.

**Focus:** A 108-case golden dataset, contextual relevancy/recall/precision, answer relevancy, faithfulness, edge-case testing, custom Claude-based judging, judge consistency, failure analysis, and pytest reporting.

🔗 [View Project 06 repository →](https://github.com/SangamnathIngalalli/rag-testing-with-deepeval)

## 🔗 Testing progression

The projects move from foundational automation toward evaluation of increasingly complex AI behavior:

**Functional Testing → Semantic Evaluation → Golden Dataset Engineering → Multi-Turn AI Testing → RAG Application Testing → RAG Evaluation & Judge Validation**

| Stage | Quality question |
|---|---|
| **01 — Functional testing** | Does the AI application behave as expected? |
| **02 — Semantic evaluation** | How relevant, correct, and safe is the generated response? |
| **03 — Dataset engineering** | How can reusable test data support evaluation and regression? |
| **04 — Conversational testing** | How does behavior hold across multi-turn conversations? |
| **05 — RAG application testing** | Can the application retrieve documents and answer from its knowledge base? |
| **06 — RAG evaluation** | How well do retrieval and generation perform, and how reliable is the evaluator? |
